**🎓 Edusity** - University Website
Edusity is a modern, responsive university website designed to showcase detailed information about the institution. It features course offerings, infrastructure highlights, student testimonials, and an integrated contact form for easy communication with university management.

**🚀 Features**

✅**Course Information**: Explore all available programs with detailed descriptions.

✅**Campus Infrastructure:** Virtual tour of campus facilities and amenities.

✅**Student Testimonials:** Real experiences shared by students and alumni.

✅**Contact Form:** Easy-to-use form to reach university staff.

✅**Fully Responsive:** Optimized for all devices — mobile, tablet, and desktop.

**🏗️ Tech Stack**
**Frontend:** HTML5, CSS3, JavaScript, React.js

**Styling:** Tailwind CSS (for fast, responsive UI design)

**✨ Highlights**
Clean, modern UI with intuitive navigation.

Built for speed, accessibility, and mobile-first experience.

Easily scalable and customizable for different institutions.
